# Domestic Intelligence Web — Roadmap Boundary

The Web/PWA remains the public synthetic prototype and compatibility surface. The authoritative product roadmap is owned by the private `DomesticIntelligence` repository and the real Google Home technical spike is owned by `DomesticIntelligence-Mobile`.

## Near term

- Keep the 2D map/device experience coherent with the native product direction.
- Use Domestic Intelligence-owned category/icon semantics rather than provider branding as the default visual language.
- Demonstrate provider-neutral import/placement concepts only with synthetic data where useful.
- Preserve portable property-schema compatibility where approved.
- Continue to keep credentials, privileged identifiers and live device access out of this public repository.

## Future compatible concepts

The public prototype may later demonstrate synthetic versions of:
- asset photographs and installation evidence;
- service layers such as electrical/plumbing/HVAC/network;
- progressive technical detail;
- property-role/scoped-access UX;
- moving/property-handover journeys.

## Parked for Web

- real Google Home credentials/authentication;
- privileged provider control;
- real customer device data;
- protected provider adapter logic;
- production authority.

3D/AR/LiDAR remain later product concepts and should not distract from the current map-first 2D experience.
